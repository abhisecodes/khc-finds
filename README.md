# KHC Finds — Premium Curated Product Discovery Platform

A lightweight, modern, mobile-responsive curated product discovery website built with pure HTML5, CSS3, and Vanilla JavaScript (ES6).

## Features
- **Mobile-App UI Style**: Clean, modern mobile-app interface leveraging system-ui fonts and smooth responsive grid layouts.
- **Adaptive Drawer Modals**: Product details slide up as a native-feeling bottom sheet on mobile screens, and center as an overlay window on desktop screens.
- **Client-side Filtering & Search**: Instant, local searching and filtering by category blocks with zero network delay.
- **No Node/React Build Step**: Served instantly as a static website with zero build dependencies, enabling maximum loading performance and minimal layout shift.

## Local Development
Open `index.html` directly in your browser, or spin up a simple server:

```bash
# Using Python
python -m http.server 3000

# Using Node (if serve is installed)
npx serve
```
