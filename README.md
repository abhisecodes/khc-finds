## KHC Finds - Premium Affiliate Discovery Portal

A high-performance, responsive single-page static website built with pure HTML, CSS, and Vanilla JavaScript. 

### Features
- **Real-Time Filter Dashboard**: Instant client-side search, categories, and tags.
- **Specifications & Spec Sheet Modal**: Interactive overlay displaying deal prices, descriptions, specifications, pros/cons, and direct affiliate checkout CTAs.
- **Premium Glassmorphic Styling**: Elegant layout featuring Outfit & Inter typography with light/dark theme support.
- **Zero Node/React Dependencies**: Served instantly from Edge CDNs with absolute minimum loading overhead.

### Local Development
Open `index.html` directly in your browser, or spin up a simple server:
```bash
# Using Node/npx
npx serve

# Using Python
python -m http.server 3000
```
